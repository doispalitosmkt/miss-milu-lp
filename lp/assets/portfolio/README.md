# Imagens do portfólio

- `carrossel/`: fonte oficial da seção Portfólio e do carrossel do hero.
- `catalogo.php`: ferramenta local que identifica automaticamente as imagens de cada segmento.
- `catalogo.js`: catálogo estático carregado pela página e gerado pela ferramenta PHP.

Para adicionar ou substituir fotos no site, use somente `carrossel/` e siga o
guia disponível em `carrossel/README.md`.
